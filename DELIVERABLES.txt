THE 7 TRAINING SPLITS

3d  - Push/Pull/Legs       (48 sets) - Intermediate

5d  - PPL Intenso          (60 sets) - Advanced

HOW TO USE
==========

1. IMPORT
   import { TRAINING_SPLITS, getRecommendedSplit } from '@/data/trainingSplits'
   import { generateWorkoutForDay, calculateWeeklyVolume } from '@/utils/splitLogic'

2. SELECT SPLIT
   const split = getRecommendedSplit(4, 'intermediate')

3. GENERATE WORKOUT
   const workout = generateWorkoutForDay(splitId, dayIndex, level, location)

4. TRACK VOLUME
   const volume = calculateWeeklyVolume(workoutHistory)
   const status = checkVolumeStatus(volume.chest, 'intermediate')

5. SHOW DASHBOARD
   <TrainingSplitDashboard profile={profile} workoutHistory={workouts} />
